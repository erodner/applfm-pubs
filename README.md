# ApplFM Publications

BibTeX entries ([`applfm.bib`](applfm.bib)) for publications that mention the DFG project **ApplFM** in the paper itself (acknowledgment or funding statement).

**Project:** Berlin Initiative for Applied Foundation Model Research (ApplFM) — DFG Research Impulses (FIP 12), Project-ID **528483508**, funding period 04/2024–03/2029. See the [BHT project page](https://projekt.bht-berlin.de/impact/forschung/berlin-initiative-for-applied-foundation-model-research-appl-fm) and the [HTW Berlin research catalog entry](https://www.htw-berlin.de/forschung/online-forschungskatalog/projekte/projekt/?eid=3601).

## Inclusion criterion

A paper is included only if its full text mentions the project — either by name ("ApplFM" / "Berlin Initiative for Applied Foundation Model Research") or by the DFG Project-ID 528483508 (often written as "Project-ID 528483508 - FIP 12"). Each acknowledgment was verified individually (last checked: 2026-09-09); the exact funding wording is quoted as a comment above each entry in `applfm.bib`.

**Excluded:** *RamanBench* (arXiv 2605.02003) surfaced in searches due to author overlap, but its full text contains no mention of the project or the DFG.
